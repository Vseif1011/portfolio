Crab detection for MATE ROV 2026

YOLOv11OpenCVPythonuv

Task 2.1 asks the ROV to count invasive European Green Crabs among two native species in an image with many resized and rotated crabs. I built the detection library behind it, as a clean API that the ROV workspace pulls in as a dependency. I compared a YOLO model against SIFT/ORB feature matching for the job.

  • Trained on about 5,000 collected, cleaned, and augmented images.
  • Kept the library separate from the ROS node so the team could integrate it quickly.
